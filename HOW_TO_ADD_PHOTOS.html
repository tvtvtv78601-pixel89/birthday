📸 How to Add Photos to the Website

✨ Good News! Adding photos is super easy! Choose any method below.

🌟 Method 1: Simple Image Replacement (Recommended)

Step 1: Prepare Your Photos
  • Select 6 beautiful photos of Hina G
  • Save them as: photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg, photo6.jpg
  • Place all photos in the same folder as index.html
Step 2: Open index.html in a Text Editor
  • Right-click on index.html
  • Select "Open With" → Choose "Notepad" or any text editor
Step 3: Find the Photo Gallery Section
  • Press Ctrl+F (Find)
  • Search for: photo-gallery
  • You'll find 6 photo placeholders
Step 4: Replace Each Placeholder

Find this code:

<div class="photo-placeholder">PHOTO_1</div>

Replace it with:

<img src="photo1.jpg" alt="Hina G" style="width: 100%; height: 250px; object-fit: cover; border-radius: 15px;">

Repeat for all 6 photos (photo1.jpg through photo6.jpg)

Step 5: Save and Test
  • Save the file (Ctrl+S)
  • Double-click index.html to open in browser
  • Navigate to Screen 4 to see your photos! 🎉

🎨 Method 2: Using CSS Background Images

Step 1: Prepare photos (same as Method 1)
Step 2: Open styles.css in a text editor
Step 3: Add this code at the end of the file: 
/* Custom Photo Backgrounds */
.photo-card:nth-child(1) .photo-placeholder {
    background-image: url('photo1.jpg');
    background-size: cover;
    background-position: center;
    color: transparent;

💡 Method 3: Keep Placeholders (No Photos)

If you don't have photos ready, that's okay! The website works beautifully with the placeholders labeled PHOTO_1 through PHOTO_6.

You can add real photos later anytime using Method 1 or 2.

⚠️ Common Issues:
  • Photos not showing? Check that file names match exactly (case-sensitive)
  • Wrong photo order? Rename your files to match photo1.jpg through photo6.jpg
  • Photos too big? The website automatically resizes them - don't worry!
  • Different image format? Use .jpg, .jpeg, or .png - all work fine!

🎯 Pro Tips

  • Use high-quality photos for best results
  • Portrait or square photos work best
  • Make sure faces are clearly visible
  • Mix different moments: smiles, candid shots, special occasions
  • Photos will automatically fit the layout - no need to resize manually
  • You can use more or fewer than 6 photos (see README.md for details)
