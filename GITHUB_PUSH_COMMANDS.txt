📋 STEP-BY-STEP GITHUB PUSH GUIDE
═══════════════════════════════════════════════════════════════

STEP 1: GitHub pe Repository Banayein
─────────────────────────────────────────────────────────────

1. Browser mein jayein: https://github.com/new
2. Repository name: "birthday-hina-g" (ya koi bhi naam)
3. Description: "Birthday surprise website for Hina G"
4. Privacy: PRIVATE select karein (secret rakhne ke liye!)
5. "Create repository" button click karein
6. Ye page open hoga - commands dikhai denge


STEP 2: PowerShell Mein Ye Commands Run Karein
─────────────────────────────────────────────────────────────

Pehle folder mein jayein:

cd C:\Users\Admin\Desktop\hi


Git Initialize karein:

git init


Sab files add karein:

git add .


First commit banayein:

git commit -m "Initial commit: Birthday surprise website for Hina G"


Branch name set karein:

git branch -M main


IMPORTANT: Ye command mein apna GitHub username dalein!
Replace YOUR-USERNAME with apna actual username:

git remote add origin https://github.com/YOUR-USERNAME/birthday-hina-g.git


Push karein:

git push -u origin main


═══════════════════════════════════════════════════════════════
🔐 AGAR PASSWORD MAANGE (Git Credentials)
═══════════════════════════════════════════════════════════════

GitHub ab passwords accept nahi karta, Personal Access Token chahiye:

1. GitHub pe jayein: https://github.com/settings/tokens
2. "Generate new token" → "Classic" select karein
3. Note: "Birthday website deployment"
4. Expiration: 30 days (ya jo chahein)
5. Scopes: "repo" checkbox select karein
6. "Generate token" click karein
7. Token copy kar lein (ye phir se nahi dikhega!)

Jab push command run karenge:
- Username: Apna GitHub username
- Password: Token paste karein (jo copy kiya tha)

🆘 COMMON ERRORS & SOLUTIONS
═══════════════════════════════════════════════════════════════

Error: "git is not recognized"
Solution: Git install karein: https://git-scm.com/download/win


Error: "Permission denied (publickey)"
Solution: HTTPS use karein, SSH nahi
         URL aisa hona chahiye:
         https://github.com/username/repo.git


Error: "Repository not found"
Solution: Check karein:
         - Repository name correct hai?
         - Username correct hai command mein?
         - Repository private hai? (access check karein)


Error: "failed to push some refs"
Solution: Pehle pull karein:
         git pull origin main --allow-unrelated-histories
         Phir push karein:
         git push -u origin main
