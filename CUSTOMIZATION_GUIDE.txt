📸 ADD/CHANGE PHOTOS
═══════════════════════════════════════════════════════════════

Method 1 (HTML):
File: index.html
Lines: ~77-112

Replace:
   <div class="photo-placeholder">PHOTO_1</div>

With:
   <img src="photo1.jpg" alt="Hina G" style="width: 100%; height: 250px; object-fit: cover; border-radius: 15px;">

Method 2 (CSS):
File: styles.css
Add at end:

.photo-card:nth-child(1) .photo-placeholder {
    background-image: url('photo1.jpg');
    background-size: cover;
    background-position: center;
    color: transparent;
}

═══════════════════════════════════════════════════════════════
🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Website won't open?
   → Make sure you're opening index.html, not another file

Changes not showing?
   → Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)

Layout broken?
   → Check if you accidentally deleted a closing tag like </div>

Colors look wrong?
   → Make sure color codes start with # and have 6 characters

JavaScript not working?
   → Check browser console (F12) for error messages

Photos not showing?
   → Verify file names match exactly (case-sensitive!)
